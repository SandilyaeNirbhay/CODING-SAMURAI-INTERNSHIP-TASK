# Employee Attrition Analysis using Python

## Project Overview
This project focuses on analyzing employee attrition patterns using Python and data visualization techniques. The analysis helps identify factors influencing employee turnover, including department, gender, job role, overtime, job satisfaction, and salary distribution.

The project uses multiple visualizations and analytical charts to understand workforce trends and employee retention patterns effectively.

---

## Features
- Employee Attrition Analysis Dashboard
- Department-wise Attrition Analysis
- Gender Distribution Analysis
- Job Role Attrition Comparison
- Overtime vs Attrition Analysis
- Job Satisfaction Impact Analysis
- Salary Distribution Analysis
- Data Visualization using Python

---

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Dashboard Components

### 1. Attrition by Department
- Bar chart showing employee attrition across different departments.

### 2. Attrition by Gender
- Pie chart representing gender-wise attrition distribution.

### 3. Attrition by Job Role
- Comparative bar chart displaying attrition across job roles.

### 4. Overtime vs Attrition
- Analysis of employee overtime impact on attrition rates.

### 5. Job Satisfaction vs Attrition
- Visualization showing relationship between job satisfaction and employee turnover.

### 6. Salary Distribution by Attrition
- Histogram and KDE plot analyzing salary distribution for attrition categories.

---

## Key Insights
- Attrition rates vary across departments and job roles.
- HR Executive and Sales Executive roles show comparatively higher attrition.
- Gender-wise attrition distribution is nearly balanced.
- Employees working overtime tend to show higher attrition patterns.
- Job satisfaction levels influence employee retention.
- Salary distribution differs between employees who stayed and employees who left.
