# Employee Demographic Analysis Dashboard

## Project Overview
This project focuses on analyzing employee demographic data using Microsoft Excel. The dashboard helps understand workforce distribution, department-wise salary trends, gender representation, and employee age patterns through interactive visualizations.

---

## Features
- Interactive Employee Dashboard
- Department Filter using Slicer
- Gender Distribution Analysis
- Average Salary by Department
- Employee Age Distribution
- Dynamic Charts and Visual Insights
- Professional Dashboard Design

---

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization Techniques

---

## Dashboard Components
### 1. Gender Distribution
- Pie chart representing male and female employee percentages.
- Helps understand workforce gender balance.

### 2. Average Salary by Department
- Bar chart comparing department-wise average salaries.
- IT department shows the highest average salary.

### 3. Age Distribution
- Histogram displaying employee age frequency.
- Helps identify dominant workforce age groups.

### 4. Department Slicer
- Interactive slicer for filtering dashboard by department.
- Enables dynamic analysis.

---

## Key Insights
- Male employees represent 51% of the workforce, while female employees represent 49%.
- IT department has the highest average salary among all departments.
- HR department shows comparatively lower average salary.
- Most employees belong to the mid-age workforce category.
- Interactive filtering improves demographic analysis efficiency.
