# Sales Metrics Dashboard

## Project Overview
This project is an interactive Sales Metrics Dashboard created using Microsoft Excel. The dashboard helps analyze monthly sales performance, revenue trends, and top-performing products through visual charts and KPI cards.

## Features
- Interactive Month Slicer
- Monthly Revenue Trend Analysis
- Top Products Analysis
- KPI Cards for:
  - Total Revenue
  - Total Sales
  - Average Order Value
- Dynamic Pivot Charts
- Professional Dashboard Design

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization Techniques

## Key Insights
- Total Revenue generated is ₹23,33,000.
- Jackets are the top-performing product category.
- Revenue trend shows higher sales in the beginning months.
- Dashboard allows interactive month-wise filtering using slicers.
